Predicting Student Academic Performance python · scikit-learn

Compared five ML algorithms on the UCI Student Performance dataset — logistic regression reached 94.9% accuracy predicting pass/fail, and a linear model hit R² = 0.75 predicting exact final grades. Feature-importance analysis found absences and prior course failures were the strongest predictors after prior grades.

BruinSeat python

A UCLA course seat-availability monitor built around a pluggable, fully-tested architecture — 7 passing unit tests cover seat-opening detection and a simple trend model that predicts when a full section is likely to open up. The live network call is isolated from the logic on purpose, so everything except one HTTP request is independently testable.

QuickSort Performance Benchmark python

Implemented QuickSort from scratch and benchmarked it against Python's built-in sort on randomized lists up to 1,000,000 integers — the built-in sort won by 6–8x, a concrete look at why implementation-level optimization matters as much as asymptotic complexity.
